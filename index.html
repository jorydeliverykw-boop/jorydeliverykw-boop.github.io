AbuKhaled Collector Backup

A private backup utility operated by Abu Khaled for his market-data collector and paper-trading research project.

Purpose

The utility uploads collector backup files to the owner's Google Drive after explicit authorization. It downloads uploaded backups to check file integrity and test database restoration.

Google Drive access

The application requests only the drive.file permission. Access is limited to files created by the application or explicitly made available to it. It does not request access to the owner's entire Google Drive.

This utility is for the owner's private use. It does not execute real-money trades.
