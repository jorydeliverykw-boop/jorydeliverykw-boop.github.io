AbuKhaled Collector Backup
Updated: 12 October 2026

Operator and purpose

This application is operated by Abu Khaled for private backup and recovery of his market-data collector. Contact: jorydeliverykw@gmail.com.

Information accessed

The application requests the Google Drive drive.file scope. It accesses backup contents and file metadata for files it creates or files explicitly made available to it. It does not request unrestricted access to Google Drive.

How information is used

Data is used to upload backups, locate application files, download backups for integrity checks, and test database restoration. Operational records may include timestamps, file identifiers, sizes, verification results, and hashes.

Storage and service providers

Backups are stored in the owner's Google Drive. The application runs on Render, where local backup data, operational records, and OAuth credentials are stored. Google and Render process data as infrastructure providers.

Credentials and security

OAuth credentials are used only to provide the authorized backup functionality. The refresh token is stored on the service's persistent disk with restricted file permissions. Tokens are not intentionally included in public source code, chat messages, or application logs.

Sharing and limited use

Google user data is not sold, used for advertising, or used to train AI models. It is not shared with unrelated third parties. Its use is limited to the backup and recovery functions described here and follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Cloud backups remain until the owner deletes them. Revoking authorization stops future authorized access but does not automatically delete existing backups or local records. The owner can delete Drive backups directly and request deletion of stored credentials and local records using the contact address below.

Control and revocation

The owner can revoke the application's access through Google Account third-party connections at any time.
